# НСИ · Этап 1

Инструмент НСИ для работы с иерархией оборудования, моделями и ТОР.
Реализован первый этап ТЗ:

* отображение и правка иерархии оборудования (дерево с разворачиванием/сворачиванием);
* карточки узлов верхних уровней (предприятие/завод/цех/участок/группа) с
  произвольными атрибутами и описанием;
* таблица моделей и ТОР под выбранным узлом (с учётом вложенных уровней);
* нормализация кода модели по 13 правилам п.8.3 ТЗ;
* классификация моделей по справочнику Класс/Подкласс
  (по ключевым словам и regex-шаблонам);
* ручное переопределение Класс/Подкласс с приоритетом над автоматикой;
* загрузка иерархии и моделей из Excel/CSV;
* загрузка пользовательского справочника-классификатора из Excel/CSV;
* отметка «Проверено экспертом» в карточке ТОР.

## Стек

* Vite + React + TypeScript;
* zustand — стор состояния;
* xlsx (SheetJS) — парсинг Excel/CSV.

## Формат импортируемой иерархии (xlsx/csv)

Колонки (распознаются по русским заголовкам, регистр и пробелы не важны):

* `Предприятие`, `Завод`, `Цех`, `Участок`, `Группа` —
  уровни иерархии. Любую можно оставить пустой.
* `Код модели` — код, прикрепляемый к самому нижнему непустому уровню
  строки.
* `Класс`, `Подкласс` (опционально) — если уже известны, попадают
  в соответствующие поля модели.

Пример:

| Предприятие   | Завод   | Цех    | Участок          | Группа        | Код модели |
|---------------|---------|--------|------------------|---------------|------------|
| ООО «Демо»    | Завод 1 | Цех 1  | Воздухоснабжение | Вентиляторы   | ВЦ-12,5    |
| ООО «Демо»    | Завод 1 | Цех 1  | Электроснабжение | Машины электр.| АД225-5УХЛ |

## Формат классификатора

Колонки: `Класс`, `Подкласс`, `Ключевые слова` (через запятую),
`Шаблоны` (regex, через запятую). Шаблон или ключевое слово,
найденное в нормализованном коде модели, означает совпадение.

## Правила нормализации (п.8.3 ТЗ)

См. <code>src/domain/normalize.ts</code>. Все правила пронумерованы
комментариями `p1…p13`. Применённые к каждой модели правила
показываются в карточке ТОР.
